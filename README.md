# 健儿宝童装批发微信小程序

项目分为 `frontend`（微信小程序）和 `backend`（Java 服务）。小程序包含顾客端和管理端：顾客可浏览商品、管理购物车并生成订单；管理员可维护分类与商品，并处理订单。

## 启动后端

确保本机 MySQL 已启动，并按实际情况设置环境变量：`DB_URL`、`DB_USERNAME`、`DB_PASSWORD`。默认连接本机 `root/root`，会尝试创建 `shop_mini_program` 数据库。

在 `backend` 目录执行：

```powershell
mvn spring-boot:run
```

服务地址为 `http://127.0.0.1:8080`。第一次启动会写入演示分类和商品。

修改后端代码后需要重启服务。启动时会自动创建门店资料表，并为商品添加 Base64 图片字段。管理端上传的门店封面、老板娘微信二维码和商品图片会以 Base64 保存到 MySQL；单张原图请控制在 3 MB 以内。

本次启动还会自动为门店、分类和商品添加中英文数据字段。已有数据会以原有名称和描述作为中文初始值，英文内容需要在管理端补充。新建门店资料、商品分类和商品时，中文与英文名称均为必填项；商品描述和门店公告也可分别维护中英文版本。

## 运行小程序

使用微信开发者工具导入 `frontend` 目录。开发工具中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”后，运行即可连接本机服务。

内置账号：顾客端 `user / user123`，管理端 `admin / admin123`。登录页为演示入口，会自动使用相应账号。

管理员登录后，在“店铺”页维护中英文门店资料并上传门店封面和微信二维码；在“分类”页录入分类的中英文名称；在“商品”页录入中英文名称、描述、图片和库存后上架。顾客端顶部按钮切换中英文时，会同步切换界面文案、门店资料、分类、商品和订单中的商品快照。
